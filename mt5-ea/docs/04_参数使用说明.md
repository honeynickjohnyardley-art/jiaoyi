# v1.19 参数使用说明

只说明新增功能。原有参数的含义与用法不变。**以下所有数字都是说明用的示例，不是默认值，也不是任何一笔交易的建议；每笔任务的参数仍须由你当次明确给出。**

## 1. 价格区间开仓

| 参数 | 填法 |
|---|---|
| `Sx_Condition` | 选 `价格区间` |
| `Sx_RangeLow` | 最低价 |
| `Sx_RangeHigh` | 最高价（必须大于最低价） |
| `Sx_Threshold` | 不使用，留 0 |

- 买入用 **Ask**、卖出用 **Bid** 判断（与原规则一致）。
- 两端都包含：最低价 ≤ 价格 ≤ 最高价。
- 判断两次：检查时刻一次，下单调用前按最新报价再一次。任一次不满足都不下单，任务结束，不补单。

示例（纳指做空，27960 ≤ Bid ≤ 29190）：`Condition=价格区间`，`RangeLow=27960`，`RangeHigh=29190`，`Direction=卖出`。

## 2. 账户货币金额止盈止损

| 参数 | 填法 |
|---|---|
| `Sx_StopsMode` | 选 `账户货币金额` |
| `Sx_TPMoney` | 盈利多少止盈（正数） |
| `Sx_SLMoney` | 亏损多少止损（正数） |
| 其余止盈止损参数 | 不使用 |

换算方式：

1. 用 MT5 的 `OrderCalcProfit` 按**本次品种、手数、方向**测出每个最小价格变动的盈亏（券商合约规格和货币换算都包含在内）。
2. 止盈取最接近目标金额的价位；止损**向下取整**，理论亏损不超过目标金额。
3. 再用 `OrderCalcProfit` 反算两个价位的金额。与目标的偏差超过一个最小价格变动即判为验证未通过，不下单。
4. 成交后按**实际成交价**重新定位止盈止损（沿用价格差模式的调整流程），并在日志里写出按实际成交价核算的金额。

示例（纳指 0.1 手、盈利 60 止盈、亏损 20 止损）：按规则文档"1 手 1 价格单位 = 1 美元"，0.1 手每个价格单位 0.1 美元，换算结果为止盈距离 600、止损距离 200。实际数值以运行时 `OrderCalcProfit` 为准，启动日志会给出换算预览。

**实际盈亏会偏离目标金额的原因：**

- 止损是到价后按市价成交，跳空或快速行情下成交价可能差于止损价，亏损会超过目标。
- 金额只算"开仓价 → 止盈/止损价"的价差，不含手续费和隔夜利息。
- 开仓瞬间的点差已经付出：刚开仓时浮亏约等于点差。卖单止损按 Ask 触发、买单止损按 Bid 触发。
- 非账户货币计价的品种，换算汇率在持仓期间会变化。
- 金额太小（不足一个最小价格变动，或换算出的距离小于券商最小止损距离）时不下单，不会自动放大。

## 3. 最大允许点差

| 参数 | 填法 |
|---|---|
| `Sx_MaxSpread` | 允许的最大点差，单位是**价格单位**（Ask − Bid），与规则文档里的点差数字同一口径。0 = 不限制 |

- 例：黄金填 `1.0` 表示 Ask−Bid 大于 1.00 时不下单。
- 点差恰好等于上限时允许。
- 检查两次（检查时刻、下单调用前）。超限即不下单并记录原因，**不在容错窗口内等待点差回落**。
- 日志同时给出换算后的点数，便于与 MT5"市场报价"核对。

## 4. 三项可以任意组合

区间 + 金额止盈止损 + 点差上限可同时使用，也可只用其中任意一项；与原有的 ≥ / ≤ / 到点直接执行、固定价格 / 价格差模式互相兼容。

## 5. 必须知道的规则

1. **同一组、同一目标日期、同一收盘时间只能执行一次。** 事件编号不含价格和方向。某组的任务一旦有了结果（包括"条件不满足""已错过""跳过"），在不改日期或收盘时间的情况下改条件再启用，不会再执行。新任务请改日期/时间，或换一个空组。
2. 修改任何参数都会让 EA 重新初始化，需要重新连续运行 30 秒才会"就绪"。**不要在检查时刻前 2 分钟内改参数**，否则该任务记为"已错过"。
3. "仅记录信号"模式下任务同样只处理一次，之后改回"允许交易"也不会再执行。
4. 面板上的"本次结果"行只保存在内存里，EA 重新加载后消失，完整记录以日志文件为准。
5. 旧 `.set` 文件可直接加载到 v1.19：缺少的新参数取默认值 0，效果与 v1.18 相同。v1.19 保存的 `.set` 加载回 v1.18 时，新参数被忽略；但如果该 `.set` 用了新选项（条件 = 4 或止盈止损模式 = 2），v1.18 会判为参数无效而不交易。

## 6. 日志怎么看

每个任务的结果是一行，字段用 ` | ` 分隔：

`【结果】 检查时刻（北京/服务器） | 事件编号 | 方向 手数 | 判断用价（含 Bid/Ask 与报价时间） | 点差（及上限） | 条件 | 判断 | 止盈止损设定 | 换算/计算结果 | 发单前复核报价 | 原因 | 下单返回`

真实样例见 `tests/sample_logs.txt`。
