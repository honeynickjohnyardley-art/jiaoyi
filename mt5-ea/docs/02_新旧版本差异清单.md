# v1.18 → v1.19 差异清单

| 项目 | v1.18（生产） | v1.19（开发版） |
|---|---|---|
| 文件 | `SessionCloseEntry.mq5` | `SessionCloseEntry_v119.mq5`（新文件，不覆盖旧文件） |
| 行数 / 字节 | 2,941 / 125,416 | 3,339 / 148,354 |
| MD5 | `6951af7fb3e0679a9b0b4ce768ccd8b5` | `685fa7a35dfb076204463737b30acc12` |
| `#property version` | 1.18 | 1.19 |

改动规模：新增约 478 行，改写约 80 行。原有 136 个输入参数的名称、类型、默认值**逐一核对无变化**。

## 一、新增参数（每组 5 个，共 25 个；默认值全部为 0 = 不启用 = 旧行为）

| 参数 | 含义 | 何时生效 |
|---|---|---|
| `Sx_RangeLow` | 区间最低价 | 开仓条件选"价格区间"时 |
| `Sx_RangeHigh` | 区间最高价 | 同上 |
| `Sx_TPMoney` | 止盈金额（账户货币） | 止盈止损模式选"账户货币金额"时 |
| `Sx_SLMoney` | 止损金额（账户货币） | 同上 |
| `Sx_MaxSpread` | 最大允许点差（价格单位，Ask−Bid） | 大于 0 时 |

## 二、新增下拉选项（原有选项的编号不变）

| 参数 | 新选项 |
|---|---|
| `Sx_Condition` | `4 = 价格区间：最低价 ≤ 价格 ≤ 最高价` |
| `Sx_StopsMode` | `2 = 账户货币金额` |

## 三、逻辑改动

| # | 位置 | 改动 | 对旧任务的影响 |
|---|---|---|---|
| 1 | `PriceCondMet`（新） | 价格条件判断集中到一个函数，增加区间判断 | ≥ / ≤ / 到点直接执行的判断结果与旧版相同 |
| 2 | `RunCheck` | 条件满足后增加点差检查；日志增加点差、未满足原因 | 未设点差上限时无影响 |
| 3 | `MoneyToDistances` / `ComputeStops` | 金额模式：`OrderCalcProfit` 换算 + 反算验证 | 仅金额模式 |
| 4 | `FinalSendCheck`（新）/ `SendOrder` | "发送中"记录建立后、下单调用前，按最新报价统一复核：报价有效性 → 价格条件 → 点差 → 止盈止损重算 → 交易时段/品种模式/手数/止盈止损合法性/已有持仓/挂单/近期成交/保证金 → 交易权限。取代 v1.14 只针对价格差模式的重算 | **更严格**：条件在检查后发生变化时不再下单 |
| 5 | `EnsureStops` / `StopsConfirmStep` | 金额模式复用价格差模式的成交后调整流程；确认后追加按实际成交价核算的金额 | 价格差/固定价格模式流程不变 |
| 6 | `CheckSlotParams` / `LogSlotWarnings` | 新参数校验与启动提示（区间上下限、金额必填、点差非负、金额换算预览） | 旧参数校验规则不变 |
| 7 | `RecordEvent` / `UpdateDisplay` | 面板每组增加"点差上限"字段和"本次结果"行（检查报价、点差、未执行原因） | 仅显示 |
| 8 | `OnInit` | 启动日志标明 v1.19；图表品种与任务品种不一致时写一条提示并显示在面板 | 仅提示 |
| 9 | 头部注释 | 删除与事实不符的"未经编译/未测试"警告，增加 v1.19 说明 | 无 |

## 四、未改动（逐项确认）

- 事件编号格式 `SCE_<Magic>_<组>_<日期>_<HHMM>`、状态码 1–16、单实例锁 `SCELOCK_<Magic>`、日志文件名 `SessionCloseEntry_<Magic>.log`
- 时间与时区计算、夏令时规则、服务器偏移推算
- 就绪机制（120 秒 / 连续运行 30 秒）、运行连续性检测、容错窗口
- 交易时段判断（含 v1.16 跨午夜修正）
- 下单后核对、止盈止损补设、平仓及其核对
- 仅记录信号模式、仅限模拟账户开关
- 按星期重复模式（保留原样，未扩展）
- 面板绘制方式（OBJ_LABEL、折行）

## 五、行为变化汇总（升级后需要知道的）

1. 发单前多一道复核。只会让"原本会下的单在条件变化后不下"，不会反向。
2. 条件不满足时的日志多了"原因："字段；价格差模式发单前失败的标题文字由"下单前按最新报价计算止盈止损未通过"改为"发单前安全复核未通过"。
3. 启动日志第一行由 `EA 启动` 改为 `EA 启动（v1.19）`。
4. 面板可能多 1–2 行。
