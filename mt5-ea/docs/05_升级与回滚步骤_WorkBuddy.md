## 阶段 C：切换实盘图表（⚠ 需用户明确授权后才执行）

前提：阶段 A、B 全部通过并已回传，用户书面确认"可以切换实盘"。建议选在三个品种都没有待执行任务、且没有本 EA 持仓的时段。

对三个图表**逐个**执行，做完一个核对一个：

1. 记录该图表当前面板全文和 EA 参数（或确认与 `当前实况参数_Magic<号>_*.set` 一致）。
2. 从图表移除 `SessionCloseEntry`（v1.18）。
3. 把 `SessionCloseEntry_v119` 拖到同一图表，在参数页加载对应的 `当前实况参数_Magic<号>_<品种>.set`。**不改任何参数**，确认 Magic、运行模式、各组启用状态与步骤 1 的记录一致后点确定。"允许算法交易"的勾选保持与原来一致。
4. 核对：
   - 日志出现 `EA 启动（v1.19）`，Magic 正确；
   - 面板各组的品种、方向、手数、条件、止盈止损、状态与步骤 1 一致（新参数均为 0，不显示点差上限）；

## 回滚

任何阶段都可以回滚，生产文件始终没有被改动。

1. 从图表移除 `SessionCloseEntry_v119`。
2. 把 `SessionCloseEntry`（v1.18，原 `SessionCloseEntry.ex5`）拖回该图表，加载同一份 `当前实况参数_Magic<号>_*.set`，核对 Magic 与启用状态后确定。

4. 事件记录（终端全局变量）两版共用：v1.19 期间处理过的任务，回滚后 v1.18 不会重复执行。
5. 注意：如果某组在 v1.19 期间用了新选项（价格区间 / 账户货币金额），回滚到 v1.18 后该组会显示"参数无效"而不交易。回滚前把这类组停用，或另行告知用户。
6. `SessionCloseEntry_v119.mq5/.ex5` 可留在目录里，不挂载就不会运行。
